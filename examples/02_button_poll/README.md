# 02. Кнопка: опрос и антидребезг

Программа сама, десять раз в секунду и чаще, читает уровень на выводе кнопки. Подтверждённое нажатие увеличивает счётчик, пишет строку в монитор и переключает светодиод.

Опрос проще прерывания, и для одной медленной кнопки его достаточно. Платить за простоту приходится тем, что задача просыпается даже когда кнопку никто не трогает.

## Схема кнопки

Как в исходном проекте с дисплеем:

- один контакт кнопки — GPIO9;
- второй контакт — земля (GND);
- внутренняя подтяжка GPIO к 3.3 В включена программно.

Пока кнопку не нажимают, `gpio_get_level()` возвращает 1. Нажатие даёт 0. Такая кнопка называется активной по низкому уровню.

На платах ESP32-C3 кнопка BOOT обычно уже распаяна на GPIO9 по этой схеме. Отдельную кнопку можно не подключать: подойдёт BOOT.

| Сигнал | GPIO |
| --- | --- |
| Кнопка, активный уровень 0 | 9 |
| Светодиод | 8 |

## Что такое дребезг

Контакт кнопки — это пружина. В момент замыкания она ударяется и несколько миллисекунд подпрыгивает. Осциллограф показывает не один перепад, а пачку. Пауза 30 мс (`DEBOUNCE_MS`) после первого срабатывания отсекает эту пачку: если через 30 мс уровень всё ещё 0, нажатие настоящее.

Вторая пауза стоит на отпускании, иначе дребезг размыкания сразу засчитается новым нажатием.

## Сборка

```bash
. $HOME/esp/esp-idf/export.sh
cd examples/02_button_poll
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

## Как устроен код

1. GPIO9 — вход с подтяжкой вверх, без прерывания.
2. GPIO8 — выход светодиода.
3. Цикл спит по 10 мс. Это и есть период опроса. Кнопку человек не нажимает быстрее, так что 10 мс достаточно, чтобы не пропустить касание.
4. После подтверждённого нажатия цикл ждёт, пока уровень снова станет 1. Поэтому длинное удержание — это одно событие, а не поток.

`gpio_get_level()` возвращает `int`: 0 или 1. Сравнивать его нужно с нулём явно. Не стоит использовать само значение как булево «нажато»: у этой кнопки как раз наоборот, нажато — это ноль.

## Что вы должны увидеть

Каждое нажатие BOOT (или вашей кнопки на GPIO9):

```text
I (xxx) button_poll: нажатие 1, светодиод включён
I (xxx) button_poll: нажатие 2, светодиод выключен
```

Если за одно касание счётчик прыгает на несколько единиц, увеличьте `DEBOUNCE_MS` до 50.

## Когда опроса уже мало

Опрос неудобен, если:

- нажатие нужно заметить, пока задача занята другой долгой работой;
- кнопок много и хочется спать, пока ни одна не нажата;
- событие короткое, короче периода опроса.

Тогда переходят к прерыванию: [03. Кнопка по прерыванию](../03_button_interrupt/README.md). Исходный проект с OLED как раз так и устроен.
