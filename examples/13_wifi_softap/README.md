# 13. Wi-Fi SoftAP: своя точка доступа

Плата сама создаёт сеть:

| Параметр | Значение |
| --- | --- |
| Имя (SSID) | `ESP32C3-DEMO` |
| Пароль | `esp32c3demo` |
| Канал | 1 |
| Адрес платы | `192.168.4.1` |
| Адреса клиентов | выдаёт DHCP, обычно `192.168.4.2` и дальше |

Подключите телефон или ноутбук к этой сети так же, как к роутеру. Интернет через плату при этом не появится: у неё нет второго канала наружу. Это отдельная сеть из двух устройств.

В мониторе каждое подключение и отключение печатается вместе с MAC-адресом клиента. Раз в десять секунд пишется, сколько клиентов на связи сейчас. Больше четырёх одновременно пример не принимает (`AP_MAX_CLIENTS`).

## Чем AP отличается от станции

В [примере 12](../12_wifi_station/README.md) плата искала чужую сеть. Здесь чужая сеть не нужна, плату видно в списке Wi-Fi телефона.

Режим задаёт `esp_wifi_set_mode`:

- `WIFI_MODE_STA` — только клиент;
- `WIFI_MODE_AP` — только точка доступа;
- `WIFI_MODE_APSTA` — оба сразу, например принять телефон и самой выйти в домашний роутер. В этом примере второй половины нет.

Интерфейс создаёт `esp_netif_create_default_wifi_ap()`. Вместе с ним поднимается DHCP-сервер. Адрес `192.168.4.1` — значение по умолчанию этого интерфейса, его можно сменить через `esp_netif_set_ip_info`, если подсеть нужна другая.

## Сборка

```bash
. $HOME/esp/esp-idf/export.sh
cd examples/13_wifi_softap
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

## Что вы должны увидеть

```text
I (xxx) softap: точка "ESP32C3-DEMO" поднята. Адрес платы 192.168.4.1
I (xxx) softap: клиент 1a:2b:3c:4d:5e:6f подключился, всего aid=1
I (xxx) softap: сейчас подключено клиентов: 1
```

`aid` — внутренний номер клиента на точке доступа, для одного телефона это 1.

## Частые ошибки

- Сети нет в списке телефона. Прошивка ещё не дошла до `esp_wifi_start`, или телефон сидит в диапазоне 5 ГГц и прячет сети 2.4 ГГц. Имя вводится вручную: `ESP32C3-DEMO`.
- Телефон пишет «неверный пароль». В коде пароль `esp32c3demo`, девять символов, без пробела. Пароль короче 8 символов WPA2 не примет, и `esp_wifi_set_config` вернёт ошибку ещё на старте.
- Телефон подключился и ругается, что интернета нет. Для этого примера так и задумано.
