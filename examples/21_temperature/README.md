# 21. Температура кристалла

Раз в секунду пример читает встроенный датчик и печатает градусы Цельсия. Проводов нет: датчик внутри ESP32-C3.

Это температура кремния, а не комната. Сразу после прошивки значение близко к воздуху. Если рядом в коде включить Wi-Fi и непрерывно что-то передавать, цифра вырастет: радио греет кристалл. В этом примере радио выключено, поэтому ряд получается спокойный.

Окно `10…50` в `TEMPERATURE_SENSOR_CONFIG_DEFAULT` выбирает режим измерителя. Для платы на столе оно нормальное. Если унести плату на мороз, окно надо сдвинуть, иначе точность или сам вызов чтения станут хуже.

## Сборка

```bash
. $HOME/esp/esp-idf/export.sh
cd examples/21_temperature
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

## Что вы должны увидеть

```text
I (xxx) temp: датчик включён, окно 10…50 °C. Это температура кристалла
I (xxx) temp: 28.43 °C
I (xxx) temp: 28.51 °C
```

Положите палец на металлический экран модуля на десять секунд. Число должно заметно поползти вверх и потом вернуться. Если не ползёт, палец на корпусе USB-разъёма, а не на экране чипа, либо модуль закрыт толстым пластиком.

## Как устроен код

1. `temperature_sensor_install` создаёт датчик с выбранным окном. Ручка `sensor` дальше нужна всем вызовам.
2. `temperature_sensor_enable` реально включает измерение. До этого ручка есть, а читать рано.
3. `temperature_sensor_get_celsius` кладёт результат в `float`. Формат `%.2f` печатает два знака. Сотые доли не означают такую точность датчика: шум младшего разряда обычен.

Выключить измерение, если оно больше не нужно, можно парой `temperature_sensor_disable` и `temperature_sensor_uninstall`. В бесконечном примере они не вызываются.
