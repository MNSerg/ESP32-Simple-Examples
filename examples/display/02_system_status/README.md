# Характеристики платы на u8g2

Тот же OLED 72×40 показывает живые данные чипа. На стекло не влезает всё сразу, поэтому страниц четыре, и программа сама меняет их раз в три секунды. Кнопка GPIO9 переключает страницу сразу и заново откладывает автолистание.

| Страница | Что на ней |
| --- | --- |
| Чип | `ESP32-C3` и частота из `CONFIG_ESP_DEFAULT_CPU_FREQ_MHZ` |
| Память | Свободная куча и минимум за время работы |
| Время | Секунды с запуска и причина последнего сброса |
| Кристалл | Температура внутри чипа и начало версии ESP-IDF |

Точки внизу — номер текущей страницы. Проводка совпадает с меню: SDA GPIO5, SCL GPIO6, кнопка GPIO9, адрес `0x3C`.

Температура — датчик кристалла, не воздух. Пока радио и процессор работают, она выше комнатной. Если датчик не открылся, на странице будет `--`, программа при этом не останавливается.

## Сборка

```bash
. $HOME/esp/esp-idf/export.sh
cd examples/display/02_system_status
idf.py set-target esp32c3
idf.py build
idf.py -p /dev/ttyACM0 flash monitor
```

Компонент `u8g2` при первой сборке скачивается из интернета.

## Как устроен код

Запуск дисплея такой же, как в меню и в `project-name`. Датчик температуры настроен окном 10…50 °C: для работающей платы в комнате этого хватает, за окном драйвер может вернуть ошибку, и тогда на стекле остаётся `--`.

Цикл раз в 30 мс смотрит кнопку и часы. Страница перерисовывается не чаще раза в секунду, чтобы числа памяти и температуры обновлялись, но шина не была занята постоянно. Каждая перерисовка дублируется в монитор: экран можно проверять и без стекла перед глазами.

Причина сброса читается через `esp_reset_reason()`. «питание» — обычное включение, «watchdog» — сторож из примера 20, «deep sleep» — пробуждение из примера 17.

## Что вы должны увидеть

Экран листает четыре страницы. В мониторе примерно так:

```text
I (xxx) status: Чип | ESP32-C3 | 160 МГц
I (xxx) status: Память | 250000 б | мин 248000
I (xxx) status: Время | 12 с | питание
I (xxx) status: Кристалл | 32.4 C | IDF v6.1.0
```

Числа будут другими. Нажатие BOOT (GPIO9) сразу открывает следующую страницу.

## Частые ошибки

- Температура всегда `--`. Окно 10…50 °C не подходит для очень холодной или уже горячей платы. Границы задаются в `TEMPERATURE_SENSOR_CONFIG_DEFAULT`.
- Страницы не листаются кнопкой. GPIO9 должен замыкаться на землю, как BOOT на большинстве плат ESP32-C3.
- После сна или сброса сторожа страница «Время» показывает не «питание». Так и задумано: это причина последнего пробуждения, а не способ, которым вы хотели включить плату.
