# Дисплей u8g2

Два проекта для того же OLED, что в `project-name`: SSD1306 72×40, адрес `0x3C`, SDA GPIO5, SCL GPIO6, кнопка GPIO9 на землю. Библиотека та же, `u8g2` через `u8g2_esp32_hal`. Картинки из исходного проекта здесь не повторяются.

| Папка | Что на экране |
| --- | --- |
| [01_flexible_menu](01_flexible_menu/README.md) | Вложенное меню из таблицы пунктов. Короткое нажатие листает, длинное выбирает |
| [02_system_status](02_system_status/README.md) | Живые характеристики чипа: память, время работы, причина сброса, температура кристалла |

Экран узкий, поэтому строки короткие. Шрифт `u8g2_font_5x8_t_cyrillic` рисуется через `u8g2_DrawUTF8`: обычный `u8g2_DrawStr` кириллицу из этого шрифта не покажет.

Первая сборка скачивает u8g2 из интернета. Остальным примерам в `examples/` эта библиотека не нужна.
